# 7. export-skill — 회사 양식 전용 스킬 만들기

"우리 회사 보고서 전용 스킬 만들어줘", "동료에게 줄 스킬로 묶어줘" 일 때. 먼저 onboard 가 끝나 있어야 한다.

1. 스킬 이름(영문 소문자·하이픈)과 트리거 문장 3개를 정한다. 사용자가 안 주면 제안하고 진행.
   - 트리거 = 사람들이 실제로 하는 말 ("월간 보고 만들어줘", "경영회의 자료")
2. 실행
   ```
   python SKILL_DIR/scripts/make_company_skill.py profiles/<이름> --skill-name <영문이름> --triggers "말1,말2,말3" --out dist
   ```
3. `dist/<영문이름>.zip` 전달 + 업로드 방법 안내 (README 3절)
4. 안내: 양식이 바뀌면 onboard 를 다시 하고 zip 을 다시 만든다. 회사 양식이 들어 있으니 **공개 저장소·외부 공유 금지**.
