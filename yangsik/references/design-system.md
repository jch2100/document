# 디자인 시스템 (PPTX) — 컨설팅 스타일

컨설팅 회사 보고서(전략 컨설팅 덱)의 공통 관례를 표준화했다. 특정 회사의 로고·이름·글꼴을 흉내 내지 않고 **구조와 원칙**만 따른다.

## 1. 원칙 5가지
1. **제목 = 결론 (액션 타이틀).** 주제어("현황")가 아니라 문장("이용률이 3년째 하락해 31%까지 내려옴"). 2줄·45자 이내. 장 제목만 이어 읽어도 보고 전체가 이해돼야 한다.
2. **한 장 = 한 메시지 = 근거 하나.** 제목에 '그리고'가 들어가면 장을 나눈다.
3. **모든 숫자에 출처.** 표·차트가 있는 장은 '출처' 슬롯 필수 (check: `missing_source`).
4. **색은 아껴 쓴다.** 남색(primary) + 회색이 기본. 강조색(accent)은 "봐야 할 한 곳"에만 (추천안 열, 강조 막대 하나).
5. **장식 금지.** 그림자·3D·클립아트·그라데이션 없음. 가로선과 여백으로 구조를 만든다.

## 2. 화면 구조 (16:9, 인치)

```
0.36  ┌ 트래커   (11pt 굵게, 강조색)  예: "2. 원인"
0.64  │ 제목     (24pt 굵게, 남색, 위쪽 기준 → 1줄이든 2줄이든 시작 위치 같음)
1.58  ├──────────── 구분선 (회색 0.75pt) ────────────
1.88  │
      │ 내용 영역 (1.88 ~ 6.45)
      │   채운 뒤 실제 분량을 재서 '시각적 중심'(남는 공간의 38%를 위에)에 배치
6.45  │
6.58  │ 출처     (9pt, 회색, 왼쪽 아래)
7.02  └ 회사명/로고 (8pt)                          쪽번호 (8pt, 오른쪽)
```

## 3. 그리드 — 12단
- 좌우 여백 0.6in, 단 사이 0.25in, 1단 ≈ 0.78in
- 2단비교 6+6 · 3단카드 4+4+4 · 프로세스 3+3+3+3 · 차트 8 + 시사점 4 · 매트릭스 7 + 해설 5 · 이미지 7 + 설명 5 · 빅넘버 6 | 6

## 4. 타입 스케일 (pt) — 이 크기만 쓴다

| 용도 | 크기 | 굵기 |
|---|---|---|
| 큰 숫자 (빅넘버) | 66 | 굵게 |
| 표지 제목 | 36 | 굵게 |
| 섹션 제목 | 32 | 굵게 |
| 핵심 메시지 문장 / 마무리 제목 | 30 | 굵게 |
| **액션 타이틀** | **24** | 굵게 |
| 카드 제목·숫자 | 22 | 굵게 |
| 강조 본문(본문 레이아웃, 부제) | 18 | 보통 |
| 머리띠·칸 제목 / 기본 본문 | 16 | 굵게 / 보통 |
| 2단계 본문 | 14 | 보통 |
| 표 · 3단계 본문 · 축 이름 | 12 | 보통 |
| 차트 글자 · 트래커 | 11 | 보통 / 굵게 |
| 출처 | 9 | 보통 |
| 꼬리말 | 8 | 보통 |

본문 3단계: ■ 16 → – 14 → · 12 (단계마다 -2pt). 줄 간격 115%, 1단계 앞 간격 10pt.

## 5. 정렬 규칙

| 대상 | 가로 | 세로 |
|---|---|---|
| 제목·본문·카드 | 왼쪽 | 위 (묶음 전체는 시각적 중심) |
| 머리띠(2단비교·프로세스) | 왼쪽 | 가운데 |
| 카드 제목 | 왼쪽 | 아래 (본문과 붙게) |
| 표 머리글 | 왼쪽 (숫자 열은 오른쪽) | 아래 |
| 표 셀 | 왼쪽, **숫자는 오른쪽** (자동 판별) | 가운데 |
| 시사점·이미지 설명 | 왼쪽 | 가운데 |
| 매트릭스 축 이름 | 세로축 왼쪽 위, 가로축 오른쪽 아래 | — (세로쓰기는 프로그램마다 깨져서 쓰지 않음) |
| 쪽번호 | 오른쪽 | 가운데 |

가운데 정렬은 쓰지 않는다 (한글 줄바꿈 시 들쭉날쭉해지고, 정렬선이 사라진다).

## 6. 표·차트
- **표**: 머리글 굵게 + 굵은 아래선, 행은 가는 회색 가로선, 세로선·배경색 없음, 첫 열 굵게, 마지막 행 아래 남색선. `highlight_col` 로 추천안 열만 연한 배경 + 강조.
- **차트**: 눈금선·값 축 없음, 데이터 레이블 직접 표시, 첫 계열 남색·나머지 회색, `highlight` 로 막대 하나만 강조색. 원그래프는 가능하면 막대로.

## 7. 레이아웃 14종 — 무엇을 말할 때 쓰나

| 레이아웃 | 이럴 때 |
|---|---|
| 표지 | 첫 장 |
| 목차 | 5장 이상일 때 흐름 |
| 섹션 | 15장 이상일 때 단락 구분 |
| 3단카드 | **요약(상황·발견·제언)**, 세 가지 축, KPI 셋 |
| 빅넘버 | 숫자 하나가 결론 |
| 차트 | 추이·비교 + 시사점 |
| 표 | 대안 비교, 일정, R&R |
| 2단비교 | 전/후, 문제/원인, 나쁜 예/좋은 예 |
| 매트릭스 | 2x2 우선순위 |
| 프로세스 | 4단계 추진 방식 |
| 본문 | 개조식 근거 (다른 레이아웃이 안 맞을 때) |
| 핵심메시지 | 요약·전환 한 문장 |
| 이미지 | 화면·구성도 |
| 마무리 | 요청 사항·다음 단계 |

## 8. 바꿀 수 있는 것 / 없는 것
- 바꿈: `theme/*.yaml` 의 색 6개·글꼴·회사명·로고 → 10종 일괄 (`build_templates.py`, 회사 양식에서 자동 추출은 `standardize.py`)
- 고정: 위치·크기·정렬 규칙 (`scripts/ys_pptx.py` 의 디자인 토큰). 바꾸려면 코드에서 한 곳만 고치면 14종 모두 따라감.
