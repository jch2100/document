# 내용 JSON 형식

## PPTX — `slides` 목록

```json
{
  "meta": {"title": "파일 속성 제목(선택)"},
  "slides": [
    {"layout": "표지", "제목": "…", "부제": "…", "날짜·작성자": "2026. 11. 4. | 부서 · 이름"},
    {"layout": "본문", "제목": "…", "핵심메시지": "…", "본문": ["항목1", ["하위1", "하위2"], "항목2"], "노트": "발표자 노트(선택)"},
    {"layout": "표", "제목": "…", "핵심메시지": "…",
     "표": {"header": ["구분", "A안", "B안"], "rows": [["비용", "1억", "7천만"]], "col_widths": [1, 2, 2]},
     "출처": "출처: …"},
    {"layout": "차트", "제목": "…", "핵심메시지": "…",
     "차트": {"type": "bar", "categories": ["1분기", "2분기"], "series": {"실적": [95, 112]}, "number_format": "#,##0"},
     "해설": ["읽을 점"], "출처": "단위: 억 원"},
    {"layout": "이미지", "제목": "…", "이미지": "images/screen.png", "캡션": ["설명"]}
  ]
}
```

- 키 = 슬롯 이름 (profile.yaml `layouts.<레이아웃>.slots`). 없는 슬롯은 경고 후 무시.
- 값: 문자열 = 한 문단 / 목록 = 여러 문단 / 중첩 목록 = 한 단계 아래(최대 3단계).
- 강조: `**굵게**` 만. 색·크기 지정 불가(양식이 정함).
- 비워 둔 슬롯은 자동 삭제(발표 화면에 안내문이 남지 않음).
- 차트 type: `bar`(세로 막대) `hbar`(가로) `stacked` `line` `pie` `doughnut`
- 이미지 경로는 내용 JSON 파일 기준 상대경로.

## DOCX — `blocks` 목록

```json
{
  "meta": {"title": "…", "header": "머리말 문서 종류(선택)"},
  "blocks": [
    {"approval": ["담당", "팀장", "대표"]},
    {"title": "문서 제목"},
    {"subtitle": "부제"},
    {"meta": [["보고일", "2026. 11. 4."], ["보고자", "인재개발팀 김하늘"]]},
    {"summary": ["결론 한 문장", "요청 한 문장"]},
    {"h1": "추진 배경"},
    {"h2": "세부 과제"},
    {"h3": "소항목"},
    {"b": ["개조식 항목", ["하위 항목", ["하위의 하위"]], "다음 항목"]},
    {"p": "서술형 문단 (제안서·품의 문구)"},
    {"table": {"header": ["항목", "금액"], "rows": [["…", "…"]], "col_widths": [3, 1], "label_col": false}, "caption": "※ 부가세 별도"},
    {"note": "붙임  견적서 1부. 끝."},
    {"image": "images/chart.png", "width_cm": 15, "caption": "그림 1. …"},
    {"pagebreak": true},
    {"cover": {"title": "…", "subtitle": "…", "date": "2026. 11.", "company": "…"}},
    {"toc": "목차"}
  ]
}
```

- 한국어 별칭도 됨: 제목·부제·대제목(h1)·중제목(h2)·소제목(h3)·문단·개조식·참고·요약·표·정보표·결재·쪽나눔·목차·표지·그림
- 글 앞에 □ ○ - 1. 가. ※ 를 쓰면 자동 제거된다(양식 번호와 중복 방지).
- `label_col: true` → 첫 열을 라벨(연한 배경·굵게)로.
