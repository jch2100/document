# 내용 JSON 형식

## PPTX — `slides` 목록

모든 내용 장의 공통 슬롯: `트래커`(섹션 이름, 선택) · `제목`(**결론 문장**) · `출처`(숫자가 있으면 필수)

```json
{
  "meta": {"title": "파일 속성 제목(선택)"},
  "slides": [
    {"layout": "표지", "제목": "…", "부제": "…", "날짜·작성자": "2026. 11. 4. | 부서 · 이름"},
    {"layout": "3단카드", "트래커": "요약", "제목": "결론 한 문장",
     "카드1제목": "상황", "카드1본문": ["…"], "카드2제목": "발견", "카드2본문": ["…"], "카드3제목": "제언", "카드3본문": ["…"]},
    {"layout": "빅넘버", "트래커": "1. 현황", "제목": "…", "숫자": "31%", "설명": "…", "본문": ["근거1", "근거2"], "출처": "출처: …"},
    {"layout": "차트", "트래커": "1. 현황", "제목": "…",
     "차트": {"type": "bar", "categories": ["2024", "2025"], "series": {"이용료": [10400, 11100]}, "highlight": 1, "number_format": "#,##0"},
     "해설": ["시사점 1", "시사점 2"], "출처": "출처: …"},
    {"layout": "표", "트래커": "3. 대안", "제목": "…",
     "표": {"header": ["구분", "A안", "B안"], "rows": [["비용", "1억", "7천만"]], "col_widths": [1, 2, 2], "highlight_col": 2},
     "출처": "출처: …"},
    {"layout": "2단비교", "제목": "…", "좌측제목": "현재", "좌측본문": ["…"], "우측제목": "개선 후", "우측본문": ["…"]},
    {"layout": "매트릭스", "제목": "…", "세로축": "▲ 영향도", "가로축": "시급성 ▶",
     "좌상": ["이름", ["항목"]], "우상": ["이름(우선)"], "좌하": ["이름"], "우하": ["이름"], "해설": ["…"]},
    {"layout": "프로세스", "제목": "…", "단계1제목": "1. 진단", "단계1본문": ["…"], "단계2제목": "…", "단계2본문": ["…"],
     "단계3제목": "…", "단계3본문": ["…"], "단계4제목": "…", "단계4본문": ["…"]},
    {"layout": "본문", "트래커": "…", "제목": "…", "본문": ["항목1", ["하위1", "하위2"], "항목2"], "노트": "발표자 노트(선택)"},
    {"layout": "핵심메시지", "제목": "요약", "핵심메시지": "한두 문장 결론", "보조설명": "근거 한 줄"},
    {"layout": "섹션", "번호": "02", "제목": "…", "설명": "…"},
    {"layout": "이미지", "제목": "…", "이미지": "images/screen.png", "캡션": ["① …", "② …"]},
    {"layout": "목차", "제목": "목차", "본문": ["…", "…"]},
    {"layout": "마무리", "제목": "요청 사항", "본문": ["…", "문의: …"]}
  ]
}
```

- 키 = 슬롯 이름 (profile.yaml `layouts.<레이아웃>.slots`). 없는 슬롯은 경고 후 무시.
- 값: 문자열 = 한 문단 / 목록 = 여러 문단 / 중첩 목록 = 한 단계 아래(최대 3단계).
- 강조: `**굵게**` 만. 색·크기·위치 지정 불가(양식이 정하고, 세로 균형은 자동).
- 비워 둔 슬롯은 자동 삭제.
- 표: 숫자 열은 자동 오른쪽 정렬. `highlight_col`(0부터) = 추천안 열 강조. `label_col: false` = 첫 열 굵게 끄기.
- 차트 type: `bar` `hbar` `stacked` `line` `pie` `doughnut`. `highlight`(0부터) = 막대 하나만 강조색 (계열 1개일 때).
- 레이아웃 별칭: 요약→3단카드, 비교→2단비교, 단계→프로세스, 2x2→매트릭스, 숫자→빅넘버, 결론→핵심메시지
- 옛 형식(`제목`=주제어 + `핵심메시지`=결론)도 자동 변환됨: 주제어→트래커, 결론→제목.

## DOCX — `blocks` 목록

```json
{
  "meta": {"title": "…", "header": "머리말 문서 종류(선택)"},
  "blocks": [
    {"approval": ["담당", "팀장", "대표"]},
    {"title": "문서 제목"},
    {"subtitle": "부제"},
    {"meta": [["보고일", "2026. 11. 4."], ["보고자", "인재개발팀 김하늘"]]},
    {"summary": ["결론 한 문장", "요청 한 문장"]},
    {"h1": "추진 배경"},
    {"h2": "세부 과제"},
    {"h3": "소항목"},
    {"b": ["개조식 항목", ["하위 항목", ["하위의 하위"]], "다음 항목"]},
    {"p": "서술형 문단 (제안서·품의 문구)"},
    {"table": {"header": ["항목", "금액"], "rows": [["…", "…"]], "col_widths": [3, 1], "label_col": false}, "caption": "※ 부가세 별도"},
    {"note": "붙임  견적서 1부. 끝."},
    {"image": "images/chart.png", "width_cm": 15, "caption": "그림 1. …"},
    {"pagebreak": true},
    {"cover": {"title": "…", "subtitle": "…", "date": "2026. 11.", "company": "…"}},
    {"toc": "목차"}
  ]
}
```

- 한국어 별칭도 됨: 제목·부제·대제목(h1)·중제목(h2)·소제목(h3)·문단·개조식·참고·요약·표·정보표·결재·쪽나눔·목차·표지·그림
- 글 앞에 □ ○ - 1. 가. ※ 를 쓰면 자동 제거된다(양식 번호와 중복 방지).
- `label_col: true` → 첫 열을 라벨(연한 배경·굵게)로.
