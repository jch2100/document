# 내용 쓰기 가이드 (채우기 전에 읽기)

양식이 서식을 해결하므로, Claude가 책임질 것은 **내용의 구조와 문체**다.

## 1. 구조
- **두괄식**: 문서 맨 앞(요약·핵심메시지)에 결론 + 요청. 근거는 뒤.
- **한 장(한 절) = 한 메시지**. 핵심메시지만 이어 읽어도 이야기가 돼야 한다.
- 보고서 기본 흐름: 배경 → 현황·문제 → 원인 → 대안 → 기대효과 → 요청
- 의사결정 문서는 **무엇을 결정해 달라는지**가 첫 장에 보여야 한다.

## 2. 개조식 문체
- 종결: `~함` `~임` `~예정` `~필요` 또는 명사형. `~습니다`는 마무리 인사·품의 문구에만.
  - 추진하였습니다 → 추진함 / 문제가 있습니다 → 문제 발생 / 필요합니다 → 필요
- 한 항목 = 한 주장, 40자 안팎. 길면 하위 항목으로.
- 상위 항목 = 주장, 하위 항목 = 근거·세부.

## 3. 숫자
- 숫자는 단위와 함께: 1억 2,000만 원 / 15% / 7%p / 6주
- 비교는 기준을 밝힘: 전년 대비, 목표 대비
- 날짜: `2026. 11. 4.` / 기간: `2026. 11. 4. ~ 12. 31.`
- **원자료에 없는 숫자를 만들지 않는다.** 없으면 `[확인 필요: 연간 비용]` 으로 남기고 보고.

## 4. AI 티 빼기 (rules/ai-tone.yaml 이 검사)
- 금지: 혁신적·획기적·다양한·시너지·패러다임, `~하는 것이 중요합니다`, `~라고 할 수 있습니다`, 엠대시(—), 이모지
- 번역투 줄이기: `~에 있어서` → `~에서`, `~를 통해` → `~로`
- 수식어 대신 사실: "획기적 개선" → "처리 시간 40% 단축"

## 5. 분량 감각
| 슬롯 | 권장 |
|---|---|
| 제목 | 한 줄, 25자 이내 |
| 핵심메시지 | 한 문장, 45자 이내 |
| 본문 | 항목 3~6개, 하위 포함 10줄 이내 |
| 카드 | 제목 10자 이내(숫자 가능), 본문 1~3개 |
| 1페이지 보고서 | A4 1장. 넘으면 줄인다 |

## 6. 회사 문체가 있으면
profile.yaml `writing` 이 이 가이드보다 우선한다. 샘플 문서(`profiles/<회사>/samples/`)가 있으면 extract.py 로 뽑아 문장 길이·종결·용어를 따라 한다.
