# 좋은 양식 / 나쁜 양식 (등급 기준)

AI가 양식을 '지키려면' 양식에 **이름 붙은 칸**이 있어야 한다. 사람 눈에 예쁜 것과 기계가 채울 수 있는 것은 다르다.

## PPTX
| | A (좋음) | C (나쁨) |
|---|---|---|
| 칸 | 슬라이드 마스터 레이아웃에 플레이스홀더 | 슬라이드마다 텍스트박스를 손으로 그림 |
| 이름 | 레이아웃 '본문', 칸 '핵심메시지' | 'Title and Content', 'Text Placeholder 2' |
| 서식 | 레이아웃이 글꼴·크기 보유 | 글자마다 직접 크기 지정 |
| 글꼴 | 테마에 한글 글꼴 지정 | 영문 글꼴만 → PC마다 다른 한글 글꼴 |

확인법: PowerPoint → 보기 → 슬라이드 마스터. 레이아웃에 점선 상자(개체 틀)가 있으면 A~B.

## DOCX
| | A | C |
|---|---|---|
| 제목 | '제목 1/2/3' 스타일 + 자동 번호 | 굵게 + 직접 입력한 "1." |
| 목록 | 목록 스타일(자동 □ ○) | 손으로 친 □ ○ |
| 간격 | 문단 앞/뒤 간격 | 엔터 여러 번 |
| 표 | 표 스타일 | 셀마다 직접 색칠 |

확인법: Word → 홈 → 스타일 창 열고 문단 클릭 → 스타일 이름이 '표준'만 나오면 C.
