# Office 호환 점검 (실제 PowerPoint·Word에서 10분)

이 폴더의 두 파일을 **실제 PowerPoint / Word** 에서 열어 아래를 확인하세요. 각 장의 제목이 곧 확인 항목입니다.
문제가 있으면 해당 장을 캡처해서 "몇 번 장, 무엇이 다름"만 알려 주시면 됩니다.

## 0. 열 때
- [ ] **"복구" 창이 뜨지 않는다** (뜨면 가장 중요한 버그 — 즉시 알려 주세요)
- [ ] 글꼴이 맑은 고딕으로 보인다 (홈 → 글꼴 칸에 '맑은 고딕')
- [ ] Mac이면: 글꼴이 다른 것으로 바뀌어 보이는지 (확인 필요 항목)

## 1. 점검_PPT_레이아웃14종.pptx
| 장 | 확인 |
|---|---|
| 전체 | 슬라이드 쇼(F5)에서 '텍스트를 입력하십시오' 같은 안내문이 안 보인다 · 왼쪽 아래 '점검회사', 오른쪽 아래 쪽번호 |
| 1 표지 | 두 줄 제목이 화면 가운데 근처, 아래 남색 띠 |
| 2 목차 | 번호 1. 2. 3. 자동 · **한글 단어가 중간에서 끊기지 않음** |
| 4 3단카드 | 세 카드 높이 같음 · **굵게** 가 굵게 |
| 5 빅넘버 | 큰 숫자가 넘치지 않음 |
| 6 차트 | 차트 클릭 → 마우스 오른쪽 → **데이터 편집** 이 된다 (그림 아님) · 4분기만 파란 막대 |
| 7 표 | 추천 열(B안) 머리글 파란 바탕 + 열 연한 파랑 · 금액 오른쪽 정렬 · 세로선 없음 |
| 9 매트릭스 | 우상 칸만 남색, 흰 글자 |
| 10 프로세스 | 화살표 4개 한 줄, 글자가 화살표 안 |
| 11 본문 | ■ – · 3단계 · 긴 문장이 **어절 단위**로 줄바꿈 |
| 12 핵심메시지 | 큰 문장과 아래 설명이 겹치지 않음 |
| 13 이미지 | 그림이 찌그러지지 않음 |
| 14 마무리 | 보기 → 슬라이드 노트에 '발표자 노트 점검용 문장' |
| 편집 | 아무 장 본문에서 Enter → 같은 기호(■)가 이어짐 · 보기 → 슬라이드 마스터에 레이아웃 14종 이름이 한글로 |

## 2. 점검_Word_블록전체.docx
| 위치 | 확인 |
|---|---|
| 머리말 | '점검회사 \| 점검' |
| 결재란 | 오른쪽 정렬, 칸 너비 일정 |
| 제목 번호 | 1. → 가. → 1) 가 **자동** (글자를 지워도 번호가 남음) |
| 개조식 | □ ○ - 가 자동, Enter 치면 같은 기호 |
| 표 | 머리글 남색 · 추천안 열 파랑 · 금액 오른쪽 정렬 |
| 목차 | '목차' 아래 회색 글자를 오른쪽 클릭 → **필드 업데이트** → 목차가 생김 |
| 끝 | '붙임', '끝.' 앞에 ※ 없음 |
| 스타일 창 | 홈 → 스타일에 '개조식 1~3', '요약 박스', '참고' 가 있음 |
| 쪽 번호 | 아래 가운데 '- 1 -' |

## 3. claude.ai 실습
1. 설정 → 기능 → 스킬에서 옛 `yangsik` 삭제 → 최신 zip 업로드
2. 새 대화: "양식대로 스킬 환경 점검해줘" → doctor 결과 확인 (무엇이 되고 안 되는지)
3. "양식대로 스킬로 경영진 보고 PPT 만들어줘. 회사는 ○○. 내용: …"
4. 결과 파일을 내려받아 위 1번처럼 PowerPoint에서 확인

다시 만들기: `python yangsik/scripts/fill.py --template pptx/01 --content examples/00-office-check/all-layouts.json --out 점검.pptx --company 점검회사`
