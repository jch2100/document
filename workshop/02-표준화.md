# ② 표준화 — 칸 만들기

## 먼저: 두 길 중 고르기
- **브랜드 표준화 (대부분 이쪽)**: "내 양식에서 브랜드 뽑아서 표준 양식 만들어줘"
  → 색·글꼴·로고만 가져오고 구조는 표준 14종. 10분이면 끝. `brand-sample/` 의 '그린텍' 예시로 먼저 시연.
- **원본 그대로**: 공식 제출 양식처럼 바꾸면 안 될 때만 아래 과정.
- 토론: "우리 회사 양식에서 지켜야 하는 건 무엇이고, 사실은 습관이었던 건 무엇인가?"

## 자동 (B등급)
```
진단 결과대로 내 양식을 표준화해줘
```
칸 이름이 '제목/본문/부제'로, 한글 글꼴·줄바꿈이 정리됩니다.

## 반자동 (C등급) — 오늘의 본게임
1. 가장 자주 쓰는 슬라이드 3장을 고른다 (예: 표지, 본문, 비교)
2. ```
   3번 슬라이드의 상자들을 '요약' 레이아웃의 칸으로 바꿔줘. 칸 이름은 위에서부터 제목, 핵심메시지, 본문
   ```
3. PowerPoint 슬라이드 마스터에서 새 칸이 생겼는지 확인
4. 칸 이름은 **용도**로: '텍스트 2' (X) → '핵심메시지' (O)

## 손으로 하는 법 (이해용)
슬라이드 마스터 → 레이아웃 선택 → **개체 틀 삽입 → 텍스트** → 선택 창(Alt+F10)에서 이름 바꾸기

## Word
```
내 Word 양식 표준화해줘 (전부)
```
손으로 친 □ ○ → 개조식 스타일, "1. 추진 배경" → 제목 1 스타일

**체크**: 재진단 등급이 A 또는 B.
