# ④ 나만의 스킬 만들기

양식대로는 '범용' 스킬입니다. 내 회사 양식 하나만 아는 **전용 스킬**을 만들면 더 정확하고, 동료에게 zip 하나로 줄 수 있습니다.

## 구조
```
우리회사-보고/
├── SKILL.md          ← 언제 쓰고, 어떤 순서로 만드는지
├── template.pptx     ← ②에서 표준화한 양식
├── profile.yaml      ← ③
└── scripts/          ← 양식대로의 scripts 폴더를 복사
```

## SKILL.md 뼈대 (빈칸 채우기)
```markdown
---
name: <영문소문자-하이픈>          # 예: acme-monthly-report
description: "<회사> <문서> 작성. 트리거: <사람들이 실제로 하는 말 3개>"
---
# <회사> <문서>

1. profile.yaml 을 읽는다 (흐름·칸 이름·말투)
2. 사용자 자료에서 결론 한 문장을 먼저 뽑는다
3. 내용 JSON 을 쓴다 (칸 이름은 profile 그대로)
4. python scripts/fill.py --template template.pptx --content 내용.json --out 결과.pptx
5. 검증 FAIL/WARN 은 고쳐서 다시 (최대 3회)
6. 결과 + 남은 경고 + 사람이 확인할 숫자를 보고

## 이 회사만의 규칙
- <예: 표지 날짜는 'YYYY. MM.' 까지만>
- <예: 금액은 백만 원 단위>
```

## 실습
1. ```
   내 양식으로 전용 스킬 폴더를 만들어줘. 이름은 acme-monthly-report. zip으로 줘.
   ```
2. 받은 zip을 스킬로 업로드 → 새 대화에서 트리거 문장으로 호출
3. description의 트리거 문장을 고쳐 가며 잘 불리는지 시험

**체크**: 새 대화에서 "월간 보고 만들어줘" 한 마디로 내 스킬이 불린다.
