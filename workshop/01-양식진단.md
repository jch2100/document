# ① 양식 진단 — "AI가 왜 우리 양식을 무시할까?"

## 핵심 개념 (5분)
AI는 **이름 붙은 칸**만 지킬 수 있습니다. 사람 눈에 칸처럼 보여도, 텍스트박스로 그렸으면 AI에게는 '그냥 그림'입니다.

## 시연 (5분)
```
bad-samples/ai-made-bad.pptx 검사해줘
```
→ FAIL: 양식 밖 텍스트박스, 영문 글꼴만, 넘침 5배, AI 말투

## 실습 (20분)
```
내 양식(첨부)을 진단해줘. 이름은 "<회사>-<문서>".
```
1. 등급과 문제 목록을 받아 적는다
2. PowerPoint → 보기 → **슬라이드 마스터** 를 열어 진단 결과와 비교한다
   (Word: 홈 → 스타일 창 → 문단을 클릭해 스타일 이름 확인)
3. 짝과 서로의 등급을 비교: "왜 C가 나왔나?"

**체크**: 내 양식에서 '칸'이 몇 개인지 말할 수 있다.
