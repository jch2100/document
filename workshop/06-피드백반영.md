# ⑥ 결재 피드백 반영 — 전체 말고 "그 부분만"

## 핵심
다시 만들면 사람이 손댄 서식이 날아갑니다. **지목된 곳만** 바꾸고, 바뀐 내역을 남깁니다.

## 실습 (짝과 역할극)
1. 짝이 '팀장' 역할로 피드백 3개를 준다 (예: "결론이 약해", "비용 근거 추가", "요청을 앞으로")
2. ```
   팀장 피드백 반영해줘: <피드백 3개>
   ```
3. 변경 내역(`*_변경내역.md`)과 v2 파일을 팀장에게 보여 준다
4. 팀장이 한 번 더 피드백 → v3

## 정리
- 버전은 _v2, _v3 로 쌓기 (덮어쓰기 금지)
- "방향 자체가 틀렸다"는 피드백은 수정이 아니라 새로 만들기
