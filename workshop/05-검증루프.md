# ⑤ 검증 루프 — 사람 대신 검사기가 먼저 본다

## 핵심
AI는 결과를 '보지' 않고 만듭니다. 그래서 **만든 뒤 검사 → 고침 → 다시 검사** 루프가 필요합니다.

## 실습
1. 사전 준비한 내용 메모로 문서를 만든다
2. 검증 결과를 읽는다: FAIL / WARN / INFO
3. 일부러 망가뜨리기:
   ```
   본문을 '~습니다' 체로, '혁신적인', '다양한'을 넣어서 다시 만들어줘
   ```
   → 검사기가 무엇을 잡는지 본다
4. 우리 회사 금지어를 규칙에 추가:
   ```
   '만전을 기하겠습니다', '적극 검토'도 금지어로 추가해줘
   ```

## 토론
- 검사기가 못 잡는 것은? (내용이 맞는지, 숫자가 맞는지 → 사람 몫)
- 넘침 검사는 '추정'입니다. PowerPoint에서 최종 확인.
