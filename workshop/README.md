# 워크숍: 우리 회사 양식을 AI가 지키게 만들기

**목표**: 끝나면 각자 회사 양식 1개를 등록하고, 그 양식으로 문서를 만들어 주는 **나만의 스킬**을 가져간다.

| 시간 | 단계 | 산출물 | 자료 |
|---|---|---|---|
| 사전 | 환경 점검 | 체크리스트 통과 | [00-사전점검](00-사전점검.md) · [survey](survey.md) |
| 30분 | ① 양식 진단 | 등급 A/B/C + 문제 목록 | [01](01-양식진단.md) |
| 40분 | ② 표준화 | 칸(플레이스홀더)·스타일 있는 양식 | [02](02-표준화.md) |
| 30분 | ③ 프로필 작성 | profile.yaml | [03](03-프로필.md) |
| 40분 | ④ 스킬 만들기 | 내 SKILL.md | [04](04-스킬만들기.md) |
| 30분 | ⑤ 검증 루프 | PASS 문서 | [05](05-검증루프.md) |
| 30분 | ⑥ 피드백 반영 | v2 문서 + 변경 내역 | [06](06-피드백반영.md) |

**강사 메모**
- 시간이 가장 많이 드는 곳은 ②입니다. 스킬 코딩(④)보다 양식 정리가 본게임입니다.
- 디버깅 여유 시간을 30% 이상 잡으세요 (추정치. 첫 회차 후 보정).
- `bad-samples/` 의 망가진 파일로 ①⑤를 먼저 시연하면 이해가 빠릅니다.
- 약속할 수 있는 것: "결재 횟수 감소"가 아니라 **"수정 1회에 드는 시간 감소"**.
